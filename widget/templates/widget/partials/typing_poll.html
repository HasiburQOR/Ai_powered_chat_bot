{% comment %} Self-polling "typing…" indicator returned by /send/ (and re-returned by /poll/ while the reply is still generating). hx-get fires every 1.5s; when bot bubbles exist, /poll/ returns them and they replace this element via hx-swap="outerHTML" — which also removes its hx-get, so polling stops by construction. `after` is the send-time watermark that guarantees no bot bubble is missed or double-delivered. NOTE: a `{# #}` comment cannot span multiple lines in Django templates — it leaks as literal text into the page — so multi-line notes use this tag instead. {% endcomment %}
